# From Prompt to Production — Interactive Portfolio Hub

An interactive portfolio showcasing 6 complete brand identity systems, each developed through a comprehensive 14-step design process from research to delivery.

## 📚 Overview

This project demonstrates a complete design methodology through 6 distinct brands:
- **Ember & Oak** - Fine dining restaurant brand
- **OrbitX** - Civilian space tourism company
- **Bumblebee World** - Educational children's toys and books
- **NeuralDesk** - AI-powered data analysis platform
- **Verdana** - Luxury botanical skincare
- **Pawside** - Premium dog grooming products

## 🎯 Features

### Portfolio Hub (`index.html`)
- **Interactive Design**: Custom hover animations on all elements
- **6 Project Cards**: Hand-picked thumbnail images for each brand
- **Project Modals**: Click any project to explore all 13 documentation steps
- **Landing Pages**: Direct access to fully designed landing pages for each brand
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Hover Interactions**: 7-animation sequence on document links (teal border, background highlight, text color change, row slide, arrow extension, and more)

### Documentation Files
- **63 Step Documents**: Complete documentation for each brand covering:
  - Step 4: Industry Research & Market Analysis
  - Step 5: Customer Persona Development
  - Step 6: Competitor Visual Audit
  - Step 7: Design Direction Explorations (3 directions)
  - Step 8: Copywriting & Information Architecture
  - Step 10: Prompt Diary (exact prompts used)
  - Step 11: Before & After Comparisons
  - Step 13: Behance Publishing Guide

- **10 Landing Pages**: Fully responsive, interactive landing pages for all 6 brands

## 🚀 Quick Start

1. **Open the Portfolio**: Click `index.html` or visit the GitHub Pages URL
2. **Explore Projects**: Click any project card to see the 14-step process
3. **View Documents**: Click any document to read the full documentation
4. **Visit Landing Pages**: Click "View Live Site" to see the final brand designs

## 💡 Design Process

Each brand was developed through this 14-step process:

1. **Project Brief** - Series manifesto and framework
2. **Industry Scoring** - Competitive landscape analysis
3. **Brand Naming** - Naming framework and options
4. **Industry Research** - Market sizing and trend analysis
5. **Customer Persona** - Detailed user profiles
6. **Competitor Audit** - Visual analysis of 3 key competitors
7. **Design Direction** - 3 distinct visual directions explored
8. **Copywriting** - Brand voice and messaging development
9. **Landing Page** - Design implementation
10. **Prompt Diary** - Documentation of all AI prompts used
11. **Before & After** - Design evolution comparison
12. **Color & Typography** - Complete design system
13. **Behance Guide** - Publishing strategy
